## Подтверждённые дефекты и исправления

1. **NUL в строках:** ввод проходил схему, но PostgreSQL отклонял запись. Добавлена проверка контракта и регрессионные сценарии.
2. **Слишком большой HTTP body:** сервер отвечал 500 вместо 413. Исправлена обработка ограничения размера, проверен HTTP-ответ.
3. **Изоляция тестовой schema:** URL `options` мог переопределить `search_path`. Подключение проверок закрепляет выделенную schema; повторены сценарии с URL options и PGOPTIONS.
4. **Исчезновение задачи во время drag:** dnd-kit пропускал callback анимации, состояние ожидания не очищалось. Добавлены независимое завершение и очистка; повторены удаление при refetch, Escape, задержка API, 503 и следующий перенос.
5. **Сборка Render при NODE_ENV=production:** обычный npm ci исключал TypeScript и другие devDependencies; использовался глобальный компилятор Render. Установка изменена на npm ci --include=dev, для Netlify добавлен NPM_FLAGS. Замечание воспроизведено на удалённой сборке, исправление подтверждено ревьюером и успешной повторной сборкой Render.
6. **Значок Netlify поверх мобильного действия:** iframe хостинга перехватывал нажатие «Редактировать» на 360×800. Значок отключён штатной настройкой проекта. QA независимо подтвердил отсутствие iframe на 360/390/1440 px и успешный обычный pointer click кнопки на 360×800; P2 закрыт без изменения кода.

Обрезанная подпись, лишняя высота колонок и мигание действий были замечаниями пользователя. Основной агент исправил их; независимые проверки не выдаются за источник этих находок.

## Исследовательский QA

qa_exploratory независимо выполнил через Playwright CLI:

- Создание, просмотр, изменение, отмену удаления и подтверждённое удаление с повторной загрузкой; пустое состояние и создание из него.
- Пробельное название, Unicode, несохранённую форму и отмену её закрытия; название 160 символов и описание 5000 непрерывных символов на 360/390 px, без горизонтального переполнения.
- Поиск по описанию с пробелами и разным регистром, совместный фильтр приоритета, отсутствие результатов и сброс.
- Смену статуса меню с клавиатурой, mouse drag, Escape, отказ PATCH 503 с возвратом карточки и разблокировкой действий.
- Конфликт 409 с сохранностью введённого названия; отказ обновления 503 со старыми карточками, первоначальный отказ и успешный Retry.
- RAF при переносе с задержкой API 350 ms: 512 кадров, основной цвет кнопки неизменен, opacity секции и колонок всегда 1, отступ перед добавлением 14 px. Новых багов не обнаружено.

CRUD с reload проверялся на browser fixtures и подтверждает UI-поведение; реальное сохранение в PostgreSQL отдельно проверено первоначальными API/браузерными сценариями в verification.md.

После публикации тот же QA-агент независимо прошёл живую цепочку Netlify → Render → Neon: POST 201, редактирование/статус/drag, reload с сохранёнными данными и DELETE 204 своей записи. Проверены поиск по описанию, регистр/пробелы, приоритеты, отсутствие результатов/сброс, мобильные вкладки и клавиатура на 360/390 px. Консоль: 0 errors, 0 warnings. Проверочная запись удалена; три исходные демонстрационные задачи не изменялись. После исправления значка открытых подтверждённых дефектов нет.

## Границы проверки

Для ошибок и конкурентных событий использовались изолированные подмены API только в браузере; существующие пользовательские задачи не изменялись. Прогоны с PostgreSQL выполнялись в отдельной schema. Реальные мобильные устройства, Firefox/Safari, экранный диктор и нагрузочные цели не проверены. Реальная остановка/восстановление PostgreSQL не выполнена; подробности в [verification](verification.md).

Ревью дополняет фактическое исполнение и тесты и не гарантирует отсутствия всех ошибок.
