# ADR 0002: один API и общие контракты

Дата: 2026-10-16. Статус: принято.

Контекст: небольшая внутренняя доска, заданные Next/React, MUI, NestJS, PostgreSQL, ограниченный срок.

Решение: npm workspaces web/api/contracts; pg и SQL migrations; условные PATCH/DELETE с version; одна общая доска; same-origin proxy; подтверждённые сервером изменения UI.

Альтернативы: ORM полезен при сложной модели, но здесь не окупается; optimistic UI требует сложного rollback, поэтому не нужен; WebSocket и отдельный state manager не нужны; аккаунты изменили бы согласованный объём.

Последствия: простые наблюдаемые запросы и небольшой runtime. SQL и mapping поддерживаются вручную; общие схемы проверяют границы. Без авторизации использовать только в доверенной изолированной среде. Конкурентные изменения отклоняются с 409; черновик остаётся в форме.
