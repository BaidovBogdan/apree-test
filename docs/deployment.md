# Публичная демоверсия

Размещение: Next.js на Netlify, NestJS на Render Free, PostgreSQL на Neon Free. Одна общая демонстрационная доска без аккаунтов; посетители могут менять её задачи. Используются только демонстрационные данные.

## Render

Источник — публичный репозиторий BaidovBogdan/apree-test, ветка main. Runtime Node.js 24, регион Frankfurt, план Free. Конфигурация воспроизводится через render.yaml. При подключении публичного Git URL автоматическое обновление может быть недоступно; после push следует проверить деплой и при необходимости запустить Manual Deploy.

Сборка: `npm ci --include=dev && npm run build -w @apree/contracts && npm run build -w @apree/api`. Явное включение devDependencies необходимо для закреплённого TypeScript при NODE_ENV=production. Netlify использует тот же принцип через NPM_FLAGS=--include=dev.

Старт: `node scripts/migrate.mjs && node apps/api/dist/src/main.js`. Миграции выполняются перед HTTP-сервером: бесплатный тариф не предоставляет отдельную pre-deploy команду. Транзакция, advisory lock и checksum сохраняют повторяемость. При ошибке миграции сервер не стартует.

Окружение: API_HOST=0.0.0.0, API_PORT=10000, NODE_VERSION=24, NODE_ENV=production. DATABASE_URL передаётся только через секрет окружения Render и указывает на отдельную Neon БД с TLS. Строка подключения не коммитится и не передаётся Netlify или браузеру. Readiness: /api/health.

## Netlify

Base directory — корень репозитория, package directory — apps/web. Команда сборки и publish directory указаны в netlify.toml. API_ORIGIN задаётся в окружении Netlify до сборки и содержит HTTPS-адрес Render API. /api проксируется серверной частью Next.js, CORS браузеру не требуется.

NEXT_PUBLIC_API_WAKEUP=true включает ограниченное ожидание пробуждения API для чтения списка: повторяются только временные сетевые/502/503/504 ошибки, общий бюджет 90 секунд, пауза 3 секунды, каждый запрос сохраняет таймаут 10 секунд. Отмена запроса останавливает ожидание. Ошибки контракта и постоянные HTTP-ошибки не повторяются; POST/PATCH/DELETE автоматически не повторяются. После исчерпания бюджета доступно обычное действие повтора. Локальный запуск без этой переменной сохраняет прежнее поведение.

## Бесплатные лимиты

Render засыпает после простоя; первое открытие может ждать около минуты. Часы бесплатных сервисов общие для workspace. Netlify и Neon также имеют лимиты compute/трафика/сборок; для этой публикации платные планы и автопополнение не включаются. Данные сохраняются в Neon при перезапуске API. Это публичная демоверсия, а не среда для личных или конфиденциальных задач.

## Приёмка

После деплоя проверить публичный HTTPS-адрес: список, создание, изменение, перенос, перезагрузку, удаление собственной проверочной задачи, мобильную ширину и консоль. API readiness должен отвечать 200. Фактические результаты фиксируются в docs/verification.md.
