# Apree Workspace — результат

Затраченное время: примерно **1 час 20 минут**, включая разработку, проверки и ревью.

Реализованы общая канбан-доска, CRUD задач, три статуса и приоритета, перенос мышью и через меню, адаптивный интерфейс и состояния загрузки, ошибок и пустоты. Данные хранятся в PostgreSQL и проходят через NestJS API. Улучшение удобства — поиск по названию/описанию и фильтр приоритета.

Решения: Next.js / React / Material UI, общие Zod-контракты, параметризованный SQL без ORM, миграции с checksum, контроль версии для конфликтующих изменений. Перенос мгновенно обновляет доску, сохраняется в фоне и откатывается при ошибке. AI помог с реализацией, документацией и поиском пограничных случаев; результат проверялся фактическим выполнением и независимым ревью.

Проверки: 25 автоматических сценариев (5 contracts, 8 API на PostgreSQL, 12 web), TypeScript, production build, GitHub Actions и независимый QA публичной версии на компьютере и телефоне. [Открыть приложение](https://apree-workspace-baidovbogdan.netlify.app/). Локальный запуск — по [README](../README.md). Подробности — [проверки](verification.md) и [работа агентов](agent-report.md).

Ограничения: одна общая демодоска без авторизации, до 1000 загружаемых задач; нет realtime, offline и ручного порядка внутри колонки. Реальная остановка/восстановление БД и нагрузочные цели не проверены. После простоя бесплатный API просыпается около минуты.
