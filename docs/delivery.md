# Apree Workspace — результат

Затраченное время: примерно **1 час 20 минут**, включая разработку, проверки и ревью.

Реализованы общая канбан-доска, CRUD задач, три статуса и приоритета, перенос мышью и через меню, адаптивный интерфейс и состояния загрузки, ошибок и пустоты. Данные хранятся в PostgreSQL и проходят через NestJS API. Улучшение удобства — поиск по названию/описанию и фильтр приоритета.

Решения: Next.js / React / Material UI, общие Zod-контракты, параметризованный SQL без ORM, миграции с checksum, контроль версии для конфликтующих изменений. Сервер подтверждает перенос перед обновлением доски. AI помог с реализацией, документацией и поиском пограничных случаев; результат проверялся фактическим выполнением и независимым ревью.

Проверки: 13 автоматических сценариев (5 contracts, 8 API на PostgreSQL), TypeScript, production build на Windows и в Docker, браузерные сценарии компьютера и телефона. Запуск — по [README](../README.md). Подробности — [проверки](verification.md) и [работа агентов](agent-report.md).

Ограничения: одна доверенная доска без авторизации, до 1000 загружаемых задач; нет realtime, offline и ручного порядка внутри колонки. Реальная остановка/восстановление БД и нагрузочные цели не проверены.
