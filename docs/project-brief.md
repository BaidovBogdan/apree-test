# Описание продукта

Статус: **согласовано 2026-10-16**. Продукт: Apree Workspace, общая доска задач внутренней команды.

## Проблема и пользователи

- Название продукта: Apree Workspace.
- Кто пользуется: небольшая внутренняя команда.
- Проблема: видеть текущую работу, приоритеты и завершённые задачи в одном месте.
- Текущий процесс заказчиком не описан; не делаем предположений о действующих системах.
- Результат: быстрая общая доска с устойчивым хранением и понятными действиями.

## Первая версия

- Пути и критерии: [спецификация](../specs/001-task-board/spec.md).
- Объём: CRUD задач, три колонки и приоритета, перенос, поиск и фильтр, мобильный интерфейс.
- За пределами: аккаунты, несколько досок, вложения, сроки, уведомления, WebSocket, ручной порядок внутри колонки.
- Успех: все критерии AC спецификации подтверждены API-проверками и браузерными сценариями.

## Ограничения

- Платформы: современные браузеры, ширина от 360 px, мышь, клавиатура, touch.
- Интеграции: только собственный API; внешняя аналитика отсутствует.
- Хранение: PostgreSQL, постоянный Docker volume. Только локальные синтетические данные.
- Расчётная нагрузка: до 1000 задач, до 20 активных пользователей; это граница первой версии, не измеренный предел.
- Цели: API p95 < 300 ms при локальном прогретом запуске; проверять измерением. SLA и резервное копирование для внешнего размещения отдельно.
- План работ: шесть часов, включая реализацию и проверки; фактическое время в docs/delivery.md.
- Стек: TypeScript, Next.js / React, Material UI, NestJS, PostgreSQL; npm workspaces.
