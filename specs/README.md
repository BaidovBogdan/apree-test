# Спецификации функций

Здесь GitHub Spec Kit создаёт папки вида `001-feature-name/` со спецификацией, планом, задачами и дополнительными артефактами. Не копируй учебные примеры как требования продукта.

Создай первую функцию через `speckit-specify` после заполнения `docs/project-brief.md`. Поведение и критерии согласуются перед реализацией существенной новой функциональности. Общая архитектура находится в `docs/architecture/system-design.md`; локальные контракты — в папке функции.
